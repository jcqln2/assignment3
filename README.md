# Assignment 3 – React Basics: Card Deck Game

A React app that lets you manipulate a deck of cards: draw from the deck, deal 5 or 7, pick and swap or toss cards, add wildcards, and regroup /shuffle the hand.

## How to run

**For submission / grading:** Open `index.html` in your browser (double-click or File → Open). No build step required. You need an internet connection so React and Babel can load from the CDN.

**For development:** From the project folder run `npm install` then `npm run dev` to use the Vite version in `src/`.

## What’s in the repo

- **`index.html`**, **`app.js`**, **`app.css`** – Standalone version that runs when you open `index.html` (required for submission).
